Creating instructions without a builder

Unlike the functions that use an IRBuilder, these constructors create an instruction also when its operands are constants.

LLVM.SelectInst — Method
LLVM.SelectInst([pos::InsertionPoint{Instruction},] cond::Value, a::Value, b::Value,
                name::AbstractString="")

Create a select instruction that chooses between a and b based on cond, like C++'s SelectInst::Create. Unlike select!, this always creates an instruction, also when the operands are constants, and the instruction gets no debug location.

Without an insertion point, the instruction is not part of a basic block: insert it with move!, or delete it with erase!. With one, it is inserted there, e.g., SelectInst(LLVM.before(inst), cond, a, b).

The other instructions that can be created this way are ExtractElementInst, ExtractValueInst and the casts.

source
LLVM.ExtractElementInst — Method
LLVM.ExtractElementInst([pos::InsertionPoint{Instruction},] vec::Value, idx::Value,
                        name::AbstractString="")

Create an extractelement instruction that extracts element idx of the vector vec, like C++'s ExtractElementInst::Create. Unlike extract_element!, this always creates an instruction; see LLVM.SelectInst.

source
LLVM.ExtractValueInst — Method
LLVM.ExtractValueInst([pos::InsertionPoint{Instruction},] agg::Value, index::Integer,
                      name::AbstractString="")
LLVM.ExtractValueInst([pos::InsertionPoint{Instruction},] agg::Value,
                      indices::AbstractVector{<:Integer}, name::AbstractString="")

Create an extractvalue instruction that extracts an element of the aggregate agg, like C++'s ExtractValueInst::Create. The zero-based indices select the element, like for extract_value!, but need to be non-empty. Unlike extract_value!, this always creates an instruction; see LLVM.SelectInst.

source
LLVM.AddrSpaceCastInst — Method
LLVM.AddrSpaceCastInst([pos::InsertionPoint{Instruction},] val::Value, ty::LLVMType,
                       name::AbstractString="")

Create an addrspacecast instruction that casts val to the type ty, like C++'s CastInst::Create. Unlike addrspacecast!, this always creates an instruction; see LLVM.SelectInst.

The other casts are created the same way: LLVM.TruncInst, LLVM.ZExtInst, LLVM.SExtInst, LLVM.FPToUIInst, LLVM.FPToSIInst, LLVM.UIToFPInst, LLVM.SIToFPInst, LLVM.FPTruncInst, LLVM.FPExtInst, LLVM.PtrToIntInst, LLVM.PtrToAddrInst (LLVM 22+), LLVM.IntToPtrInst and LLVM.BitCastInst.
