Types

LLVM.LLVMType — Type
LLVMType

Abstract supertype for all LLVM types.

Properties

typ.context

The context in which the type was created.

source
LLVM.issized — Function
issized(typ::LLVMType)

Return true if it makes sense to take the size of this type.

Note that this does not mean that it's possible to call sizeof on this type, as LLVM types sizes can only queried given a target data layout.

See also: LLVM.bit_size.

source

LLVM.IntType — Function
LLVM.IntType(bits::Integer)

Create an integer type with the given bits width.

Short-hand constructors are available for common widths: LLVM.Int1Type, LLVM.Int8Type, LLVM.Int16Type, LLVM.Int32Type, LLVM.Int64Type, and LLVM.Int128Type.

LLVM.isemptytype — Function
isemptytype(typ::LLVMType)

Check whether the given type is empty, i.e., has no elements, or only empty elements, like C++'s Type::isEmptyTy. For example, {}, [0 x i32] and [4 x {}] are empty types.

Structure types

LLVM.StructType — Type
LLVM.StructType <: LLVMType

A structure type, representing a collection of named fields of potentially different types.

Properties

structtyp.name

The name of the structure type, or nothing if it is a literal (unnamed) structure.

structtyp.elements

The element types of the structure type, as a read-only view. Use elements! to set the body of an opaque structure type.

The properties of LLVMType are available too.

source
LLVM.ispacked — Function
ispacked(structtyp::LLVM.StructType)

Check whether the given structure type is packed.

source
LLVM.isopaque — Method
isopaque(structtyp::LLVM.StructType)

Check whether the given structure type is opaque.

source
LLVM.elements! — Function
elements!(structtyp::LLVM.StructType, elems::AbstractVector{<:LLVMType}; packed=false)

Set the body of the given structure type, i.e., its elements elems and whether it is packed (without padding between fields). This is typically used to define an opaque, named structure type.

See also the elements property.
