Passes

Functions that return the name of one of LLVM's passes, with the options given as keyword arguments, as a string for use with add! or run!. They are part of the LLVM.Passes vocabulary.

Module passes

LLVM.AddressSanitizerPass — Function
AddressSanitizerPass(; options...) -> String

The asan module pass, as a string for use with add! or run!. Keyword arguments become options of the pass, e.g., AddressSanitizerPass(; foo=true, bar=2) is "asan<foo;bar=2>", while false values become no- options.

Depending on the version of LLVM, this is the asan module pass on LLVM 16 and later, or the asan-module module pass on LLVM 15 and earlier.
